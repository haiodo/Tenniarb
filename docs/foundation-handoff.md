# Handoff: `.tenn` для дизайн-библиотеки

Что уже работает в формате и что должен сделать генератор, чтобы библиотека состояла из компонентов, а не
из нарисованных копий. Синтаксис и правила - `docs/spec/tenn-scene.md` (5b, 5c, 13) и короткий справочник
для агентов `go/mcpserver/guide.tenn.md`.

## Что появилось в `.tenn`

- **Один компонент вместо каталога вариантов:** `element "Button" { kind Component; styles { … }; item Btn { … } }`,
  вариант выбирается `use-style` внутри компонента или параметром на месте вставки.
- **Параметры:** `export let title = "Button"`, `export let kind = primary`, `export let size` (без `=` -
  обязательный). На месте вставки - по имени, без путей: `use Button as save { title "Save"; kind primary }`.
- **Стили:** `styles { primary { color …; text-color … } large { height 48 } outline one-of … }`; узел
  выбирает `use-style primary large`; каскад по порядку объявления (`use-style` как точка вставки, `at` -
  поверх); вложенные селекторы `Label { … }`; группы `one-of`/`any-of` дают инспектору список вариантов;
  `none`/`transparent` - прозрачный цвет.
- **Наследование:** `text-color` и шрифт идут вниз по дереву, цвет текста по умолчанию - контраст к своей
  заливке; иконка без цвета берёт цвет текста.
- **Вычисления:** `${…}` в сцене вычисляются (`$()` тоже), параметры - обычные переменные; список слов
  (`kind primary large`) допустим как значение параметра.
- **Шаблоны:** `template %{ … ${title} … <slot/> … %}` в компоненте; `tenniarb gen [-set имя=значение] FILE ELEMENT`
  печатает готовый текст (Svelte/React/gowt - что написано в шаблоне).

## Что должен сделать генератор библиотеки

Сейчас `dev/tenn/library/ui-kit.js` печатает по одному элементу на вариант (`Actions/Button/primary/large`,
`…/primary/medium`, ещё 40 копий плюс 32 у `ClassicButton`), и любая правка метрик множится.

1. **Определение вместо варианта.** Один `def('Actions/Button', kit.Button(...), { styles, variants })`:
   таблица стилей (`kind`, `size`, `shape`) и список комбинаций с размером каждой. `kit.component`
   (`dev/tenn/kit/10-core.js`) получает `styles` и `variants`.
2. **Печать.** `emit.mjs` печатает `element "Button" { kind Component; export let …; styles { … }; item Btn { … } }`,
   а каждая комбинация становится строкой каталога: `use Button as "Button/primary/large" { kind primary; size large }`.
   **Один блок - одна строка:** два блока в одной строке склеиваются в одну команду, второе имя теряется
   (`tenniarb check` предупреждает).
3. **Размеры для раскладки каталога.** `estimate()` не может измерить `use` - размер комбинации известен из
   `kit.Button`, его и передавать в `catalogue.mjs`, а не считать по дереву.
4. **Подбор варианта на экранах.** `useCmd` (`kit/95-library.js`) сейчас сравнивает нарисованную кнопку с
   48 деревьями. Теперь: снять с нарисованной кнопки `color/border-color/height/padding/gap/radius/font-*` и
   найти комбинацию стилей; `descendants`-пути `#i/j` заменить на `at Btn.Label { title … }` и параметры.
5. **Storybook** - истории из `variants`, дерево из одного компонента; `screens/**` и `apps/**` пересобираются
   (в них меняются только строки `use`).

## Чего в формате пока нет

- **`aspect-ratio`** - у icon-only ширина дублирует высоту в стиле размера (`min-width 48` рядом с `height 48`).
- **Нейтральный член `one-of`** - «ничего не выбрано» выражается пустым стилем (`with-icon { }`).
- **`any-of` как параметр** - список слов (`extras outlined rounded`) работает, булева значения нет.
- **Иконки двух видов** (заливка `color` против обводки `border-color`) - в стиле задаётся один цвет; нужна
  конвенция в библиотеке иконок или свойство «заливка или обводка».
- **Анимации** (`animation`, `transition`, крутилки) - предложение, раздел 13 спецификации, не реализовано.
- `transition`/`animation` пока попадают в раздел «не поддерживается» справочника.

## Проверить перед началом

- `tenniarb check PlatformDesign.tenn` - 0 ошибок и 0 предупреждений на текущей библиотеке.
- `examples/button-styles.tenn` в Tenniarb - как выглядит один компонент с 14 стилями и 4 группами:
  тот же набор вариантов, что каталог, но без копий.
- `tenniarb gen examples/*.tenn <компонент>` - как выглядит генерация кода из шаблона.
